# Dashboard screenshots

Add the project screenshots in this folder using these names so the root README displays them consistently:

| File | Recommended content |
|---|---|
| dashboard.png | Main dashboard and navigation |
| query.png | Medical query response with citations |
| knowledge-base.png | Document ingestion page |
| diagnostic.png | Diagnostic assistant workflow |
| login.png | Login page |

Use PNG or JPG files, crop out personal information, and avoid placing API keys, tokens, patient data, or other secrets in screenshots.
